# Board Game Tracker

Консольный трекер настольных игр: что куплено, сколько стоило, во что и как часто играли.

## Запуск

```bash
go run ./cmd/console
go run ./cmd/console -data /путь/к/коллекции.json
```

## Данные

По умолчанию коллекция хранится в `data/games.json`. При первом запуске файл создаётся
и заполняется стартовой коллекцией.
